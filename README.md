# euler-platform

Lerna + AWS CDK monorepo that provisioned a small “Reactshoppe” backend: API Gateway, Lambda (`/ping`, `POST /checkout`), DynamoDB orders table. Archived snapshot, as-is.

This tree is a **new public commit** with no git history. The original private archive is `eulertools/euler-platform-archive`.

## What was built (EN)

Four packages: CDK stack, API Gateway construct, DynamoDB construct, webpack-bundled Lambda handlers. Account/region from `CDK_DEFAULT_*`. No hardcoded AWS account IDs. No contract deployments.

## Qué se construyó (ES)

Backend CDK de ejemplo (checkout + ping). Sin deployments de contratos.
